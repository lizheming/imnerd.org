# Eureka 微博页面

自定义模板 `themes/eureka/template/says.eta` 使用现有 Eureka 页头、导航、页脚、明暗主题和分页样式。仅修改博客项目，不修改 Firekylin 核心或 Say 插件。

## 启用

1. 部署包含本模板的博客版本；当前项目依赖 Firekylin 2.19.1、firekylin-plugin-say 1.1.1。
2. 在后台启用 Say 插件及其设置中的公开展示开关。
3. 在「页面管理」新建公开页面，标题填「微博」，路径标识填 `says`，自定义模板选择 `says.eta`，保存并发布。页面正文可以留空，本模板展示 Say 列表。
4. 访问 `/page/says.html`；如需导航入口，在站点导航配置中增加指向该地址的链接。
5. 原 `/says` 和 `/says/:id` 仍由插件提供。不要修改路由或把此模板设为全部普通页面的默认模板。

## 登录与发布

- 访客右上角显示「登录」，进入后台登录。若当前核心登录后进入后台，回到 `/page/says.html` 即可。
- 已登录账号显示「退出」，沿用后台退出入口，退出后返回首页。
- 只有仍然启用的管理员账号显示发布框；普通账号没有发布框。服务器根据签名会话和用户表复核身份，不通过查询参数或前端标记授权。
- 页面响应为 `Cache-Control: private, no-store`，并按 Cookie 区分。不要通过 CDN 规则强行缓存此页面，否则会缓存管理员界面及 CSRF 凭据。
- 发布复用原生管理员插件表单 `/admin/api/plugins/say/forms/publish-say`，携带会话及其绑定的 CSRF 证明；最终权限仍由核心后台校验。
- 公开发布成功后返回第一页，展示新微博；默认允许这条微博评论，但仍受 Say 全局评论开关控制。私密发布成功后显示确认信息，只在后台管理，不出现在公开列表，且不开启评论。
- 请求失败或结果不确定时保留输入，不自动重试。先去后台确认是否已发布，避免重复内容。

## 展示与评论边界

- 每页 10 条公开微博，底部提供分页；空列表、插件不可用以及超出末页都有处理。
- 图片以横向缩略图展示，点击灯箱查看原图，可用左右键切换、Escape 关闭。无原生 dialog 支持时直接访问原图。语音、链接、音乐和位置内容保留基础展示。
- 时间按北京时间解释 Firekylin 的无时区时间字符串。1 分钟内显示秒、1 小时内显示分钟、1 天内显示小时、7 天内显示天数；更早显示月日，非今年显示年月日。
- 评论按钮展开 Say 已审核评论预览，支持评论分页，并链接到 `/says/:id` 的现有评论表单。评论关闭时显示提示；旧条目仍需在后台单独允许评论。
- **本次不接入 `@waline/client`。** 核心原生 Waline 后端仅解析文章/页面目标，与 Say 评论接口不兼容。按本次“不改核心，先完成主题页面”的范围，保留预览和详情页评论入口，不能宣称已有文章同款的内嵌 Waline 编辑器、回复等能力。

## 开发验证

```sh
npm install --ignore-scripts
node --test tests/says.test.js tests/says-dom.test.js
npm run build
```

测试包含真实 Eta 布局渲染、三类身份、已禁用/降权账号、私密缓存、分页、危险文本/URL、时间边界，以及 DOM 中执行实际前端脚本的发布、CSRF、重复提交、失败保留内容、评论和灯箱交互。数据和请求均为本地测试替身，不操作线上数据库。

可选真实浏览器检查：安装 Playwright 及 Chromium 后运行 `node tests/says-browser.cjs`；已有 Chromium 可设置 `CHROMIUM_PATH`。该检查拦截所有测试域名请求，不向真实站点发布。截图默认输出 `/tmp/eureka-says-desktop.png` 和 `/tmp/eureka-says-mobile.png`。

编辑 `assets/js/says.js`、`assets/css/says.css` 后同步到 `res/`（主题 build 脚本也会复制），因为部署直接分发提交的 res 文件。根目录的 `npm run build` 验证 Vercel 静态资源打包，不启动带数据库的完整站点。
